# Rcalendar releases

This repository has no published releases or installer downloads.

Current Room Calendar distribution uses:

- [Release notices](https://github.com/camster91/room-calendar-releases/releases/latest): a public version feed with no installers or application source.
- [Signed Windows installers](https://github.com/camster91/Rcalendar/releases/latest): download access requires a GitHub account with access to the private Rcalendar repository.

The app checks `camster91/room-calendar-releases` for update notices.
